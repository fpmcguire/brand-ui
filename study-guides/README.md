# Study guides

These guides support the Moderator's written study review. They are explanatory material, not
implementation or governance authority.

By Moderator decision on 2026-10-28, written guides replace interactive study quizzes. Each guide
must provide direct explanations, source/test evidence, self-check prompts, topic assessments,
unanswered questions, further-study subjects, and a gate-readiness recommendation. The Moderator
still demonstrates understanding in their own words and alone decides whether the consolidated
post-STEP-09 study-review gate is complete. The own-words demonstration does not block work from
proceeding through STEP-09; it applies only at that later gate before any release, publish, or
deployment decision.
